# 🔧 俯视图修复快速参考

## 问题
❌ visualization的系统俯视图显示为**黑色**  
❌ 文字符号无法解析（**中文乱码**）

## 根因
- 未启用 `TOP_DOWN_MAP_VLNCE` 测量
- 缺少异常处理
- OpenCV不支持中文

## 修复内容

### ✅ 文件1: `vlnce_baselines/config_system/setup.py`
```python
# setup_navigation_config() 方法中添加
if "TOP_DOWN_MAP_VLNCE" not in config.TASK_CONFIG.TASK.MEASUREMENTS:
    config.TASK_CONFIG.TASK.MEASUREMENTS.append("TOP_DOWN_MAP_VLNCE")
    print("[Config] 已启用 TOP_DOWN_MAP_VLNCE 测量")
```

### ✅ 文件2: `vlnce_baselines/vlm/navigation_visualizer.py`
**位置1**: `save_step_visualization()` - 改进俯视图获取
```python
if "top_down_map_vlnce" in info and info["top_down_map_vlnce"] is not None:
    try:
        top_down_map = maps.colorize_draw_agent_and_fit_to_height(...)
    except Exception as e:
        print(f"⚠️  俯视图渲染失败: {e}")
        top_down_map = np.zeros_like(rgb)
else:
    if step == 1:
        print(f"⚠️  info中没有top_down_map_vlnce")
    top_down_map = np.zeros_like(rgb)
```

**位置2**: `_add_text_overlay()` - 处理中文编码
```python
try:
    instruction_safe = instruction.encode('ascii', 'ignore').decode('ascii')
    if not instruction_safe.strip():
        instruction_safe = "[Non-ASCII Instruction]"
except:
    instruction_safe = "[Instruction]"
```
