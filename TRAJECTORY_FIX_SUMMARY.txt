轨迹记录修复总结
==================

## 问题描述

用户发现轨迹没有被正确记录，原因是轨迹记录发生在地图提取之后，导致当前位置的坐标转换出错。

## 根本原因

**Pipeline顺序问题：**
```
1. mapper.update() 调用 mapping_module(batch_obs, poses)
2. mapper.update() 调用 mapping_module.update_map()
   - update_map() 内部调用 get_full_map_for_rendering()
   - 提取以agent为中心的480×480地图
3. mapper.update() 调用 update_trajectory(full_pose)  ← TOO LATE!
   - 轨迹记录发生在地图已经提取之后
   - agent当前位置还没有加入轨迹
```

**结果：**
- 地图提取时，当前agent位置还没有记录到轨迹中
- 坐标转换时缺少最新的轨迹点
- 可视化时看不到轨迹

## 解决方案

将轨迹记录移到 `semantic_mapping.update_map()` 内部，**在地图提取之前**记录轨迹。

### 修改1: semantic_mapping.py

**A. 添加轨迹存储（__init__）**
```python
# Line 176-178
self.trajectory_points = []  # 当前子任务轨迹
self.global_trajectory_points = []  # 全局完整轨迹
```

**B. 添加轨迹管理方法**
```python
# Line 213-224
def clear_trajectory(self) -> None:
    """清空当前轨迹"""
    self.trajectory_points = []

def get_trajectory(self) -> List[Tuple[int, int]]:
    """获取当前轨迹"""
    return self.trajectory_points.copy()

def get_global_trajectory(self) -> List[Tuple[int, int]]:
    """获取全局轨迹"""
    return self.global_trajectory_points.copy()
```

**C. 在reset()中清空轨迹**
```python
# Line 230-232
# 清空轨迹
self.trajectory_points = []
self.global_trajectory_points = []
```

**D. 在update_map()中记录轨迹（关键修改）**
```python
# Line 939-956 - 在 get_full_map_for_rendering() 之前记录
# 同步 orientation
self.full_pose[e, 2] = self.local_pose[e, 2]

# 记录轨迹（在地图提取之前！）
agent_x_m = self.full_pose[0, 0].item()
agent_y_m = self.full_pose[0, 1].item()

# 转换为世界像素坐标
agent_px = int(agent_y_m * 100 / self.resolution)  # Y轴像素
agent_py = int(agent_x_m * 100 / self.resolution)  # X轴像素

# 避免重复记录相同位置
if len(self.trajectory_points) == 0 or self.trajectory_points[-1] != (agent_px, agent_py):
    self.trajectory_points.append((agent_px, agent_py))

if len(self.global_trajectory_points) == 0 or self.global_trajectory_points[-1] != (agent_px, agent_py):
    self.global_trajectory_points.append((agent_px, agent_py))

# 然后再提取地图
full_map = self.get_full_map_for_rendering(rotate_to_agent_heading=True)
```

**E. reset()中不再清空轨迹**

```python
    """重置建图器状态"""
    # 删除：self.trajectory_points = []
    # 删除：self.global_trajectory_points = []
    
    # mapping_module.reset() 会清空轨迹
    self.mapping_module.reset()
```

## 修复后的Pipeline

```
1. mapper.update() 调用 mapping_module(batch_obs, poses)
   - forward() 更新 local_pose[:, 2] orientation

2. mapper.update() 调用 mapping_module.update_map()
   ├─ 同步 full_pose[:, 2] = local_pose[:, 2]
   ├─ ✅ 记录轨迹（当前agent位置加入轨迹）
   └─ get_full_map_for_rendering(rotate=True)
      └─ 提取480×480地图 + 旋转

3. mapper.update() 从 mapping_module 获取轨迹
   ├─ trajectory_points = mapping_module.get_trajectory()
   └─ global_trajectory_points = mapping_module.get_global_trajectory()

4. mapper.update() 转换轨迹坐标（世界→局部）
```

## 关键改进

1. **时序正确性**：轨迹在地图提取**之前**记录
2. **单一数据源**：轨迹只在semantic_mapping中存储，避免重复
3. **坐标一致性**：轨迹使用与地图相同的世界坐标系统
4. **旋转正确性**：轨迹记录时已经有正确的agent朝向
